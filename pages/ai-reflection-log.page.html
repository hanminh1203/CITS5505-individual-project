AI Reflection Log

Overview

In this project, I used AI tools as a support mechanism for both content generation and implementation. The main areas where AI was helpful were drafting tutorial explanations, suggesting quiz content, refining page structure, and speeding up repetitive front-end coding tasks. Rather than copying AI output directly into final submission without review, I treated it as an initial draft that still required checking, editing, and testing. This was especially important because the project combines technical accuracy, visual presentation, and course-related expectations.

How I Used AI

I used AI in several stages of the project.

  • First, I used it to help draft tutorial explanations for HTML, CSS, JavaScript, and Bootstrap-related concepts.
  • Second, I used AI assistance to generate or improve quiz questions and answer choices.
  • Third, I used AI to help with interface wording and code structure for components such as quiz feedback, navigation, and layout sections.

AI was most effective when the task was specific. Broad prompts often produced generic answers, while more detailed prompts gave results that were easier to adapt into the project. For that reason, I found prompt quality directly affected output quality.

Prompts that I used

Prompt 1

Create an HTML page that explains the fundamentals of HTML, CSS, and Javascript. The content should be well-structured  and easy to follow, using examples, code snippets, and interactive demonstrations to help users understand the material.

AI output summary: The AI produced topic summaries, code examples, and suggested ways to present material in sections. This helped form the early structure of the tutorial page.

Corrections made: I rewrote parts that were too generic, corrected some explanations, and aligned the content more closely with course topics as well as the style of the website. For example: some code snippets were too simple or its styling did not support responsive.

Prompt 2

You are tasked to create 30 quiz questions about HTML, CSS, Bootstrap, and JavaScript. Each question should has 4 choices, and only 1 choice is correct answer. Format the questions in JSON format, which question has following attributes: "id": a generated question code, "question", "choices" is an array for 4 chocies, "answer" the index of the correct answer in in the array "choices".

AI output summary: The AI generated a draft question bank with answer choices and correct-answer suggestions.

Corrections made: I checked question wording, removed ambiguous or repetitive items, and adjusted difficulty so the questions better matched the tutorial content shown on the website.

What AI Did Well

AI was useful for speed, idea generation, and reducing the blank-page problem. It was particularly good at producing first drafts of explanatory text, generating examples, and suggesting alternative ways to phrase technical ideas for beginners. For a project like this, that saved time when building learning content and populating pages with enough detail to feel complete.

In addition, it was also helpful for repetitive front-end work. For example, AI can quickly suggest HTML patterns, reusable section structures, or starter JavaScript logic for event handling. Even when the generated code was not perfect, it provided momentum and reduced the time needed to assemble a working prototype.

Limitations and Problems

Eventhough AI demonstrates impressive capabilities in content generation, draft creation, it also displays notable limitations.

  • Reliability: AI often produced technically plausible answers that still needed verification. Some examples were overly broad, some wording did not match the exact course focus, and some code suggestions required debugging before they worked correctly in the browser. This means AI output could not be trusted as final just because it sounded confident.
  • Lack of Context Awareness: AI also struggles with project-specific context unless prompts are detailed. For example, it may suggest code that ignores the existing file structure, mismatches naming conventions, or assumes libraries that are not actually being used. Because of this, I had to manually integrate and test any useful suggestion.

What I Changed After Reviewing AI Output

After reviewing AI-assisted material, I made several kinds of changes. I corrected wording so concepts were clearer and closer to what was taught in class. I adjusted question wording and answer sets so they were less ambiguous. I also modified layout and interface details so the site felt more structured and visually consistent instead of looking like a direct dump of generated content. In code-related areas, I tested the behaviour manually and changed anything that did not integrate properly with the existing project files.

Reliability, Risk, and Ethics

Using AI in a coding project raises both academic and professional concerns. From an academic perspective, it is important that AI support does not replace genuine understanding.

Actions that relies too much on content generation can lead to a lack of deep understanding of the academic knowledge. If I just copied content or code without reviewing, I would risk submitting work that I could not explain or defend. That would undermine the purpose of the assignment. Therefore, I checked every piece of generated content, edited it and made sure I understood how the final implementation worked.

There are also ethical concerns around attribution and originality. AI-generated material should not be presented as if it came entirely from independent human effort. In this project, acknowledging the use of AI is important because the tutorial material and wording may have been influenced by external tools.

A further risk is hidden inaccuracy. If AI generates incorrect tutorial explanations or flawed quiz answers, it can mislead users while appearing authoritative. In an educational website, this is especially serious because users may rely on the page to learn foundational concepts. For that reason, human review remains essential.
